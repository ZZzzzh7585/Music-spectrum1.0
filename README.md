# 实时音乐频谱（Music Spectrum）

捕获电脑正在播放的声音，以动态柱状频谱实时显示。本地播放器、QQ 音乐、浏览器网页音乐等
**任何从电脑扬声器输出的声音**都能被识别并可视化。

## 功能特点

- **系统声音环路捕获**：通过 Windows WASAPI loopback 录制扬声器输出，不依赖麦克风，
  也不需要先在播放器里选输出设备。
- **实时动态频谱**：64 根对数频率柱（低频 → 高频），按 FFT 频点逐柱映射，低频无空缺；
  带峰值帽与平滑衰减，颜色由蓝青渐变到红。
- **自动音量平衡（AGC）**：动态跟踪近期响度，配合动态范围压缩与顶部封顶，
  大音量音乐不会所有柱子顶到上限，小音量音乐也能看清起伏。
- **多输出设备自动回退**：按「默认扬声器 loopback → 其他 loopback → 立体声混音」列出候选；
  当前设备持续约 4 秒检测不到声音时，自动切换到下一个候选设备。
- **轻量简洁**：仅依赖 numpy + pyaudiowpatch，界面为 Python 自带 tkinter；
  关闭窗口即释放音频设备、程序完全退出，**不驻留后台、不写开机自启项**。

## 目录结构

```
music-spectrum/
├── main.py                     # 程序入口
├── requirements.txt           # Python 依赖
├── 启动频谱.bat                 # 双击启动脚本
└── music_spectrum/
    ├── __init__.py
    ├── audio_capture.py        # 系统声音捕获（WASAPI loopback）
    ├── spectrum.py             # FFT 频谱分析与平滑
    └── gui.py                  # tkinter 实时界面
```

## 环境要求

- Windows 10 / 11
- Python 3.9 及以上（本机使用 D:\Python39，经 `py` 启动器调用）

## 安装依赖（首次运行）

在本目录打开 PowerShell / 命令行：

```bat
py -m pip install -r requirements.txt
```

## 运行方式

- 双击 `启动频谱.bat`；或
- 在本目录执行：

```bat
py main.py
```

打开后播放任意歌曲（本地文件、QQ 音乐、网页音乐均可），频谱柱会随音乐跳动。
界面顶部状态栏显示当前捕获设备与采样率；没有声音时显示“正在等待音乐播放…”。

## 工作原理

1. `audio_capture.py` 枚举 WASAPI 设备，优先打开默认扬声器对应的 `[Loopback]` 环路设备，
   后台线程持续读取音频块并转为单声道；找不到 loopback 时兜底使用“立体声混音”。
   运行中持续静音会自动 reopen 到下一个候选设备。
2. `spectrum.py` 对每块音频加 Hann 窗后做 FFT，按 FFT 频点索引把能量映射到各对数频段
   （孤立空柱由邻柱插值兜底）；AGC 跟踪近期峰值电平做动态归一化，再经伽马压缩与顶部封顶，
   最后时间平滑、峰值保持，得到 0~1 的柱高。
3. `gui.py` 每 30ms 取最新音频块分析并重绘 Canvas 柱状图。

## 常见问题

- **频谱一直不动 / 提示等待音乐**：确认电脑正在出声；程序持续约 4 秒检测不到声音时
  会自动切换到其他输出设备，可看顶部状态栏显示的设备名。若系统有多个音频输出设备
  （如显示器耳机、蓝牙音箱），请把声音从状态栏所示设备播放，或在 Windows 声音设置里
  把实际出声的设备设为默认输出。
- **提示找不到捕获设备**：声卡驱动未提供 loopback / 立体声混音；可在声音设置中
  启用“立体声混音”，或更新 Realtek / 声卡驱动后重试。
- **想调整柱数、频段范围或响度平衡**：修改 `gui.py` 中 `SpectrumAnalyzer(n_bars=64)`，
  或 `spectrum.py` 里的 `freq_min / freq_max / dyn_range_db / gamma / ceiling / decay` 参数。

## 隐私与自启说明

- 程序只在本机分析音频电平，**不录音、不保存任何音频文件、不上传数据**。
- 程序为手动启动，未注册任何开机启动项；关闭窗口后进程即结束，无后台服务。
